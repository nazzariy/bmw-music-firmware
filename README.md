# BMW Music — прошивки

Bluetooth-музика для BMW E-серії з магнітолою CIC через штатний iPod-кабель (USB + AUX) у підлокітнику:
назва треку на екрані, керування з керма та iDrive, дзвінки лишаються на штатному Bluetooth.

Цей репозиторій містить **лише готові прошивки**, з яких пристрій оновлюється сам. Код тут не публікується.

## Оновлення
Пристрій перевіряє нові версії через точку доступу телефона:
сторінка **bmw.local** (або 192.168.4.1) → Налаштування → Оновлення ПЗ → «Оновити».
Оновлюються обидві плати; невдале оновлення аудіоплати відкочується автоматично.

## Що тут лежить
| Файл | Призначення |
|---|---|
| `firmware/releases.json` | стабільні версії з описом (вибір версії, відкат) |
| `firmware/releases-beta.json` | бета-канал |
| `firmware/latest.json` | найновіша стабільна версія (для старих прошивок) |
| `firmware/bmw-music-<версія>.bin` | основна плата (ESP32-S3) |
| `firmware/bmw-music-audio-<версія>.bin` | аудіоплата (ESP32) |

Кожен образ перевіряється на пристрої за SHA-256 із маніфесту.
